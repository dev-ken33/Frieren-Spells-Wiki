# Controls & Key Bindings

Frieren Spells provides dedicated key bindings for managing spells, casting magic, switching attack patterns, and controlling mana-related abilities.

You can customize these bindings in Minecraft's **Options → Controls → Key Binds** menu. Look for the **Frieren Spells** category.

## Default Key Bindings

| Key | Action                   | Description                                        |
| --- | ------------------------ | -------------------------------------------------- |
| `I` | Open Information         | Opens the mod's information interface.             |
| `G` | Cast Spell               | Casts the currently selected spell.                |
| `R` | Spell Wheel              | Opens or interacts with the spell selection wheel. |
| `Z` | Switch Attack Pattern    | Switches the current spell's attack pattern.       |
| `X` | Switch Magic Type        | Switches the selected magic type.                  |
| `V` | Support Key 1            | Activates the first support-key function.          |
| `N` | Support Key 2            | Activates the second support-key function.         |
| `Y` | Mana Manipulation Switch | Switches the mana manipulation mode.               |
| `H` | Mana Manipulation Toggle | Toggles the mana manipulation function.            |

## Customizing Key Bindings

1. Open the Minecraft Options menu.
2. Select **Controls**.
3. Open **Key Binds**.
4. Find the **Frieren Spells** category.
5. Select an action and assign a new key.

If a key conflicts with another mod or Minecraft control, assign a different key in the settings menu.

**Note:** These are the default key bindings. Your in-game settings may differ if you have customized them. The exact behavior of each action may depend on the currently selected spell and the mod's gameplay state.
